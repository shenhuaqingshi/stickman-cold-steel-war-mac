# 火柴人冷兵器大战 · 帝国锋刃版（Stickman Cold Steel War: Imperial Edition for macOS）

一款面向 **macOS 14 Sonoma+（Apple Silicon 原生 `arm64`）** 的商业级单机冷兵器即时战略（RTS）× 宏大战略（Grand Strategy）× 统帅动作无双游戏。采用 **Swift 6（Strict Concurrency）+ SwiftUI + SpriteKit + AppKit + AVFoundation** 纯原生架构构建，零 Electron/Web 套壳、零联网依赖、零外部付费 SDK。

深度汲取 **《指尖帝国》** 的前线基地营建、农牧采矿、多兵站暴兵与文明时代攀升精髓，以及 **《罗马帝国 / 罗马：全面战争》** 的龟甲阵抗箭推进、右键拖拽拉宽/收窄战线、八象限侧翼合围、行省赋税国策与元老院拓土诏令体系，并融合标志性的 **`Tab` 键主帅提刀亲征无双**双视角无缝切换体验。

## 核心特色与商业级品质亮点

### 1. 指尖帝国式 RTS 前线营建 × 四阶文明时代演进
- **四大帝国时代（I → IV）**：从 **I 青铜军屯时代** 逐步演进至 **II 铁器城邦时代**、**III 王权帝国时代** 与 **IV 传世霸业时代**，逐级解锁高阶军事建筑、全军攻防加成与最高 **340+** 编制人口上限。
- **8 类前线可营建基地工事**：调遣随军民夫实地夯筑 **军屯民居**（+16 人口与税赋）、**帝国农庄**（持续产粮根绝断粮之忧）、**步兵军营 / 羽林靶场 / 皇家马厩 / 攻城器械所**（分类提速募兵并前推集结线）、**军械铁匠铺** 与 **警戒箭塔**（支持可视化绿/红网格幽灵选址与右键取消）。
- **铁匠铺三系三阶锻造（Lv.1~3）**：实时锻造 **百炼锋刃**（近战冲锋伤害最高 +36%）、**鱼鳞重甲**（护甲 +18、挡箭 +12%）与 **破甲羽箭**（远程器械伤害 +36%、射程 +54），并支持老兵杀敌晋升 **1~3 星金星勋章**。

### 2. 罗马全战式古战阵微操 × 统帅提刀无双双视角
- **五大古战阵与右键拉线布阵**：支持 `[1]` 重装方阵、`[2]` 雁行射击阵、`[3]` 锥形冲锋阵、`[4]` 环形铁桶阵，以及全新 **`[5]` 罗马龟甲阵（Testudo，正面与侧翼高达 85% 挡箭减伤 + 35% 护甲）**；框选军团后**按住鼠标右键横向拖拽**，即可像《罗马：全面战争》一样自由定制排兵列宽与迎敌朝向！
- **硬核冷兵器物理与士气合围**：双曲护甲（`K=50`）、长枪架枪 `3.2×` 反骑停马、半渡而击、八象限侧翼包抄/五扇区铁桶合围崩解敌军士气。
- **一键 `Tab` 化身主帅上阵**：`WASD` 八向走位，随身切换 **统帅佩刀 / 破阵大枪 / 百石硬弓**，右键起手 `0.25s` **精准弹反**触发金铁剑鸣震晕群敌，`R` 键 **三军战吼**当场唤醒白旗溃兵！

### 3. 40 城关山川疆域大地图 × 行省赋税与外交纵横
- **8 大非对称势力与 16 种特色兵种**：炎龙帝国（神机火雷戟）、苍狼汗国（怯薛重弓骑）、铁鹰公国（巨盾神弩手）、沙漠商盟（雇佣马穆鲁克）、霜原熊族（巨熊破阵者）、雾林猎盟（影袭毒弩）、玄甲重骑（铁浮图具装骑）、血月狂部（战鼓狂战士）。
- **40 座城塞 · 78 条石砌官道 · 实时 BFS 粮道**：手绘风山脉、河流、松林、沙丘与八国版图光晕沙盘；内置 **行省赋税国策**（轻徭薄赋 / 常制赋税 / 军国重敛）、**元老院三阶段拓土悬赏诏令**、围点打援设伏、丝路通商、王室联姻、背盟雪崩重罚与量化停火媾和。

### 4. Retina 披甲军团图集 × 多声道物理建模音效引擎
- **高精程序化矢量图集（`StickmanTextureAtlas`）**：全兵种配备罗马高冠红缨盔/北方狼首盔/黄金王冠、鱼鳞胸甲、随风披风、鎏金方盾、2.5D 飞檐营塞建筑、松林冠盖、鹅卵石官道与主菜单实时动态两军厮杀演武背景。
- **8 声道零延迟合成音响（`BattleAudioEngine`）**：基于 `AVAudioEngine` 物理泛音建模实时合成古罗马低沉铜角、牛皮进军战鼓、刀剑交鸣、0.25s 弹反剑吟、弓弩齐射破空、投石轰鸣、铁砧打铁与凯旋礼号。

## 在 macOS 上编译、测试与安装运行

### 1. 环境要求
- **系统与硬件**：macOS 14.0 Sonoma 或更高版本（Apple Silicon `arm64` 原生满帧优化）
- **开发工具**：Xcode 16.0 或更高版本（支持本地免证书自签名 `CODE_SIGN_IDENTITY = "-"`）

### 2. 运行全量自动化单元测试（XCTest）
```bash
xcodebuild test \
  -project StickmanWar.xcodeproj \
  -scheme StickmanWar \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath ./build
```

### 3. 一键编译 Release 正式版并安装至 `/Applications`
```bash
xcodebuild build \
  -project StickmanWar.xcodeproj \
  -scheme StickmanWar \
  -configuration Release \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath ./build

ditto ./build/Build/Products/Release/StickmanWar.app "/Applications/火柴人冷兵器大战.app"
codesign --force --deep --sign - --entitlements StickmanWar/StickmanWar.entitlements "/Applications/火柴人冷兵器大战.app"
open "/Applications/火柴人冷兵器大战.app"
```
